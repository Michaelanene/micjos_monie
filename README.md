# MicJos Monie

Cross-border money transfer app for iPhone and Android (React Native + Expo).

**Status:** early demo. Login, rates and transfers are placeholders. No real money moves.

## Run it
```
npm install
npx expo start
```
Open Expo Go on your phone and scan the QR code.

## Security
Never commit API keys, passwords or customer data. Keep them in `.env` (ignored by git).
